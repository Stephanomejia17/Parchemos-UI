# Referencia: consola de admin (congelada)

Este código es una copia congelada de la antigua app `apps/admin`
("Parchemos Console"). **No forma parte del workspace** (no aparece en
`pnpm-workspace.yaml`, no se compila ni se despliega, no se actualiza).

Sirve únicamente para que el equipo consulte los patrones visuales de UI
(dashboard, analítica, campañas, finanzas, moderación, usuarios,
verificación, soporte, IA, ajustes) mientras se construye el rol
`administrador` dentro de `apps` (ver `apps/src/modules/admin`
y `apps/src/app/admin`, donde ya vive la versión adaptada y en uso).

No edites este código esperando que tenga efecto en producción.
